# 📊 Análisis de Ventas - Alura Store Latam

## 📌 Descripción

Este proyecto realiza un **análisis exploratorio de datos de ventas** de la tienda **Alura Store Latam** utilizando **Python y Jupyter Notebook**.
El objetivo es analizar el comportamiento de las ventas, identificar tendencias y visualizar la información mediante gráficos.

---

## 🎯 Objetivos del proyecto

* Analizar los datos de ventas de la tienda.
* Identificar categorías y productos con mayor desempeño.
* Visualizar información clave mediante gráficos.
* Practicar análisis de datos con Python.

---

## 🛠 Tecnologías utilizadas

* **Python**
* **Jupyter Notebook**
* **Pandas**
* **Matplotlib**
* **Seaborn**

## 📊 Análisis realizados

En el notebook se realizan análisis como:

* Limpieza de datos.
* Análisis de ventas por categoría.
* Análisis de productos más vendidos.
